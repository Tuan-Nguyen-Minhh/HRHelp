# Evaluation directory

The active case-assessment workflow is in `case_assessment/`. It reads the benchmark,
runs the production database retrieval graph, passes the resulting passages to the
assessment graph, and calculates four RAGAS metrics. See [the workflow guide](case_assessment/README.md).

| File or directory | Required for the active workflow? | Purpose |
| --- | --- | --- |
| `case_assessment/evaluate_ragas.py` | Yes | Capture live retrieval/assessment and score the completed dataset. |
| `case_assessment/ragas_dataset.json` | Yes | Inputs, draft expected reports and reference policy passages. |
| `case_assessment/source_metadata.json` | Yes | Case IDs, dates, source facts, missing facts and provenance. |
| `case_assessment/requirements.txt` | Yes, for setup | Evaluation dependencies; application dependencies are installed separately. |
| `case_assessment/README.md` | Documentation | Commands, metric meanings and scope. |
| `case_assessment/build_dataset.py` | Only to rebuild/update cases | Reads source DOCX files and the saved policy snapshot. |
| `case_assessment/policy_snapshot.json` | Only to rebuild/audit references | Frozen reference evidence; never used as live retrieved context. |
| `case_assessment/prepare.py` | Optional | Merge outputs captured by another runner/API into the benchmark. |
| `case_assessment/results/live_retrieval/` | Generated by new runs | Completed dataset, captured passages, per-case scores and summary. |
| `case_assessment/results/fixed_evidence/` | Historical, not required | Old reports generated from predefined evidence. |
| `case_assessment/results/scored/` | Historical, not required | Old partial scoring with the application judge. |
| `case_assessment/results/scored_mistral_small/` | Historical, not required | Old scoring attempt affected by provider HTTP 429. |
| `case_assessment/results/validation/` | Historical, not required | Old validation of the draft dataset. |
| `case_assessment/results/TEST_REPORT.md` | Historical, not required | Describes the previous fixed-evidence run and its limitations. |
| `case_assessment/__pycache__/` | No | Automatically generated Python bytecode. |
| `legal_golden.json` | No, separate benchmark | 18 pinned legal-search queries from the earlier retrieval work. |
| `results/report.md` | No | Unfilled general product-evaluation report template. |

Historical outputs are retained for comparison. They are not inputs to new live runs.
The earlier retrieval runner and `retrieval_eval_*` reports were removed, as recorded
in `handoff/README.md`; `legal_golden.json` does not drive the RAGAS case evaluator.
